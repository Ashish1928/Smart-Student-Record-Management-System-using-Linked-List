#  Smart Student Record Management System Using Linked List

A professional console-based **Student Record Management System** developed in **C Programming Language** using the **Linked List Data Structure**.

This project demonstrates the practical implementation of:
. Dynamic Memory Allocation
. Linked Lists
. File Handling
. CRUD Operations
. Modular Programming



#  Project Overview

The Smart Student Record Management System is designed to efficiently manage student information in a dynamic way using linked lists.

The system allows users to:
. Add new student records
. Display all student records
. Search student details
. Update existing records
. Delete student data
. Sort records based on marks



#  Features

. Add Student Record  
. Display Student Records  
. Search Student by Roll Number  
. Update Student Details  
. Delete Student Record  
. Sort Students by Marks  
. Dynamic Memory Allocation  
. User-Friendly Console Interface
